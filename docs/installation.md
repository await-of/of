## 🚀 Installation

### 💾 NPM

```bash
npm i @await-of/of
```

Install with alias name.

```bash
npm i <alias_name>@npm:@await-of/of
```

Example:

```bash
npm i of@npm:@await-of/of
```

```js
import { of, ofAnyCase, ofError } from "of"; // <- shortened name
```

### 📈 Import

CommonJS import.

```js
const {
  Of, of, ofAny, ofAnyCase, ofCase, ofError, ofIt, ofOutcome, ofResult, ofSync
} = require("@await-of/of");
`````

ECMAScript Module.

```js
import {
  Of, of, ofAny, ofAnyCase, ofCase, ofError, ofIt, ofOutcome, ofResult, ofSync
} from "@await-of/of";
```
